# Candidate configs

Generated by `workshop/lib/fit.py` (`write_candidate`) from the calibration notebooks. Each folder holds a full config
(`performance_weights.json`, `performance_means_stds.json`) plus a `fit_manifest.json` recording which careers and
match ranges it was fitted on. They are reproducible from the data, so they are not tracked; promoting one to the
live `config/` is a deliberate step (update `config/fit_manifest.json` in the same change).
